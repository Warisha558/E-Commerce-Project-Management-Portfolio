# E-Commerce Website Development — Project Management Portfolio

## Project Overview

This repository contains a simulated Project Management case study for an e-commerce website. It demonstrates how project documentation can be organized across the five main project management phases: initiation, planning, execution, monitoring and control, and closure.

The proposed website includes product browsing, user accounts, a shopping cart, checkout, and order confirmation.

## Project Objectives

* Define project scope and requirements.
* Break project work into manageable tasks.
* Develop a proposed schedule and budget estimate.
* Identify stakeholders, responsibilities, and project risks.
* Document communication and change-control processes.
* Track planned progress, issues, risks, and milestones.
* Prepare project closure and lessons-learned documentation.
